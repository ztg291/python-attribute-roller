# python-attribute-roller

A command-line Python program I created while learning the fundamentals of Python.

## About the Project

This program allows a user to create a username and roll character attributes using a 20-sided dice system.

The character has six attributes:

* Strength
* Dexterity
* Constitution
* Intelligence
* Wisdom
* Charisma

The program also gives the user a limited number of rerolls, allowing them to choose which attributes they want to roll again.

## Running the Program

Make sure Python 3 is installed.

Clone the repository:

```bash
git clone https://github.com/ztg291/python-attribute-roller.git
```

Enter the project directory:

```bash
cd python-attribute-roller
```

Run the program:

```bash
python3 attribute_roller.py
```
